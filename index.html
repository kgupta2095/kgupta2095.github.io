Exhibit 01 · spec-to-ship

Try to slip an error into a care record

At work I own an AI summary feature in care software, where an invented detail is not a typo, it is a care record that lies. This exhibit rebuilds that guardrail idea on synthetic notes: pick one, set the model's temperament, and try to get an invented medication event past the gate.

Exhibit 02 · pm-triage-agent

File an issue. You are the gate.

My triage agent classifies raw requests and drafts the spec stub, then stops. Nothing gets filed until a human approves. This demo runs the repo's actual mock-mode rules in your browser: paste your messiest request, or use a sample.

Same keyword rules as the repo's no-API mode; the real tool uses a model for classification and spec drafting, and files GitHub issues only for approved items via a separate command. Repo.
